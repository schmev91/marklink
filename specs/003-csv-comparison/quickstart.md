# Quickstart: CSV Comparison Integration

**Date**: 2026-05-23  
**Feature**: CSV Comparison for CSV mode  
**Target**: Developers integrating CSV comparison module into marklink

## Overview

CSV Comparison adds data validation to CSV mode. Users can compare the current CSV in the editor against a reference CSV (pasted by user) and view detailed differences.

**Key Files**:
- **New**: `/js/csv-comparison.js` — comparison logic and UI
- **Modified**: `/csv.html` — load csv-comparison.js
- **Modified**: `/js/csv-app.js` — wire up Compare button
- **Modified**: `/css/style.css` — add comparison modal and diff report styles

## 1. Module Loading

Add csv-comparison.js to csv.html after csv-app.js:

```html
<!-- csv.html -->
<script src="js/csv-app.js"></script>
<script src="js/csv-comparison.js"></script>  <!-- Add this -->
```

The CSVComparison module will be global and available as `window.CSVComparison`.

## 2. Wire Up Compare Button

In `/js/csv-app.js`, add a "Compare CSV" button to the toolbar and bind it to the comparison modal:

```javascript
// In csv-app.js, in the toolbar setup section:

const compareButton = document.createElement('button');
compareButton.id = 'compare-csv-btn';
compareButton.innerHTML = '📊 Compare CSV';
compareButton.addEventListener('click', () => {
  CSVComparison.showComparisonModal(document.body);
});
toolbar.appendChild(compareButton);
```

## 3. Modal Implementation

`CSVComparison.showComparisonModal()` creates a modal overlay with:
- Input textarea for pasting reference CSV
- "Compare" button
- Result display (match/no-match badge)
- Diff report (if no match)
- Close button

### HTML Structure (auto-generated by CSVComparison module)

```html
<div id="csv-comparison-modal" class="modal">
  <div class="modal-content">
    <h2>Compare CSV</h2>
    
    <label for="reference-csv-input">Paste Reference CSV:</label>
    <textarea id="reference-csv-input" placeholder="Paste CSV data here..."></textarea>
    
    <button id="compare-btn">Compare</button>
    <button id="close-compare-btn">Close</button>
    
    <div id="comparison-result" style="display: none;">
      <div id="result-badge" class="badge"><!-- Match or No Match --></div>
      <div id="diff-report"><!-- Detailed differences --></div>
    </div>
  </div>
</div>
```

## 4. Integration Flow

```
1. User clicks "Compare CSV" button
   → CSVComparison.showComparisonModal() creates modal
   
2. User pastes reference CSV in textarea
   → User clicks "Compare"
   
3. System:
   - Gets current editor CSV from csv-preview.js or csv-editor.js
   - Calls CSVComparison.parseCSV(referenceInput)
   - Calls CSVComparison.compareCSVs(editorCSV, referenceCSV)
   - Gets formatted report via CSVComparison.formatDiffReport(diffResult)
   
4. Modal displays:
   - Green badge if match
   - Red badge + diff report if no match
   
5. User closes modal or clears reference input
   → Modal closes, returns to editing
```

## 6. CSV Data Access

The comparison module needs access to the current editor CSV. This can be obtained via:

**Option A** (Recommended): From csv-preview.js

```javascript
// In csv-comparison.js or csv-app.js integration:
const currentCSV = window.csvPreviewModule.getCurrentData();
// Expected format: Array<Array<string>> (rows)
```

**Option B**: From csv-editor.js

```javascript
const csvText = document.getElementById('csv-textarea').value;
const currentCSV = CSVComparison.parseCSV(csvText);
```

Determine which method is available by checking existing CSV mode structure. Prefer the module API if available.

## 7. Testing Workflow

1. Open `csv.html` in browser
2. Enter test CSV data in the editor:
   ```
   name,age,city
   Alice,30,NYC
   Bob,25,LA
   ```
3. Click "Compare CSV" button
4. Paste reference CSV (same or different):
   ```
   name,age,city
   Alice,30,NYC
   Bob,25,LA
   ```
5. Click "Compare"
6. Verify result:
   - If matching: Green "Match" badge
   - If different: Red "No Match" badge + diff report showing changes
7. Test edge cases:
   - Empty CSV
   - Different row counts
   - Different column counts
   - Modified cells

## 8. Debugging Tips

- Check browser console for parse errors when pasting invalid CSV
- Verify CSVComparison module loads (check `window.CSVComparison` in console)
- Use browser DevTools to inspect modal DOM structure
- Test with small CSV samples first, then larger files

## 9. Performance Considerations

- For files <1MB, in-memory comparison completes in <1 second
- Comparison is synchronous (blocks UI briefly)
- For future optimization: Could use Web Workers for very large files (>5MB), but not needed for MVP
